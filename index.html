01 / Selected work

ClearCommit

A real-time voice translation desktop app, built around a simple requirement: the conversation should keep moving while the software listens, translates, and speaks.

Python · Windows desktop · Voice AI

Speak. Understand. Keep going.

ClearCommit is a Python desktop application for two-way live voice translation. One side’s speech is recognized and translated into English captions, while the user’s microphone is translated into the other language and delivered as speech.

The project focuses on connecting speech recognition, translation, and text-to-speech into a usable live pipeline—not treating each model call as an isolated demo.

02 / Honest status

What works, and what’s still being built.

The core interpreter is the established part of the project. Additional AI coaching and meeting workflows should be treated as in development until individually connected and validated in real conversations.

Core interpreter

  • Python Windows desktop interface.
  • Two-way live voice translation workflow using speech recognition, LLM translation, and text-to-speech components.
  • Transcript display and audio-pipeline safeguards have been developed as part of the app.
  • Real-world quality and latency still need to be judged on the actual machine and network used for a demo.

AI companion features

  • Communication coaching for tone, phrasing, and clarity.
  • Meeting intelligence for decisions, action items, and unresolved questions.
  • Evidence-grounded assistant responses based on the conversation transcript.
  • These features require separate provider integration and testing; this page does not claim they are production-ready.
